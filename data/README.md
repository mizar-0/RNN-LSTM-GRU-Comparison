# Dataset

This project uses the **Limerick Dataset (OEDILF v3)** from Zenodo.

- Dataset record: https://zenodo.org/records/5722527
- DOI: https://doi.org/10.5281/zenodo.5722527
- File: `limerick_dataset_oedilf_v3.json`
- Licence: CC BY 3.0 US

Download the JSON file from the Zenodo record and place it in this directory. The training and evaluation scripts expect `data/limerick_dataset_oedilf_v3.json`.

The source material is user-submitted limericks and can contain crude, offensive, or adult language. Generated text can reproduce similar material.
